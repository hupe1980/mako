# regulatories — official primary sources

Index of the regulatory documents in this folder (retrieved 2026-07-24). Only
official primary sources (BNetzA, BDEW, DVGW).

The files themselves are **not tracked in git** — they are third-party
copyrighted publications totalling roughly 400 MB. Two things *are* tracked, so
the folder can be reconstructed from a fresh clone:

- **this index**, which carries the download URL for every hand-added
  BNetzA/BDEW/DVGW source, and
- **`bdew-mako/manifest.json`**, generated by `cargo xtask sync-regulatories`,
  which records for every mirrored EDI@Energy document its upstream id, validity
  window and content hash.

Every regulatory claim in the codebase must cite a document, section and page
from here rather than an external URL or recollection.

## Reconstructing `bdew-mako/`

```bash
cargo xtask sync-regulatories --download
```

BDEW publishes the EDI@Energy catalogue as JSON at
`https://www.bdew-mako.de/api/documents`, with one file per `fileId` at
`/api/downloadFile/{id}`. The command reconciles that catalogue against the
mirror, fetches whatever is in force and missing, and rewrites the manifest.

| Flag | Effect |
|---|---|
| *(none)* | Fetch the catalogue and report; change nothing on disk but the manifest |
| `--download` | Also fetch every in-force document the mirror lacks |
| `--offline` | Check the mirror against the committed manifest; **no network** |
| `--json` | Emit the reconciliation as JSON |

CI runs `--offline`, which needs neither the network nor the PDFs.

> **Why a content hash and not a version number.** BDEW reissues a corrected
> document under an unchanged version, so the version alone cannot say whether
> the local copy is the one a profile was read from.

The BNetzA, DVGW and BDEW-Anwendungshilfen entries below are **not** in the
BDEW catalogue and are maintained by hand; `sync-regulatories` reports them as
"not in the BDEW catalogue" and leaves them alone.

| `eeg/` | EEG 2017/2021/2023 law texts |
| `gesetze/` | BGBl law texts (EnWG amendments) |
